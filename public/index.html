Interview Qstns

Practice the questions that come up most often, and sharpen your answers.

Choose a tool to see the questions asked most often.

Playwright

  • What is Playwright and how does it differ from Selenium?
  • How do you handle waits and auto-waiting in Playwright?
  • Explain fixtures and the Page Object Model in Playwright.
  • How do you run tests in parallel and across multiple browsers?
  • How do you handle authentication state reuse (storageState)?

Selenium

  • What are the different types of waits in Selenium?
  • How do you handle dynamic elements and StaleElementReferenceException?
  • Explain the Page Object Model and its benefits.
  • How do you handle multiple windows, frames, and alerts?
  • What is the difference between driver.close() and driver.quit()?

SQL

  • What is the difference between INNER, LEFT, RIGHT, and FULL JOIN?
  • How do WHERE and HAVING differ?
  • Explain GROUP BY and aggregate functions with an example.
  • What is a subquery versus a correlated subquery?
  • How would you find duplicate rows in a table?

Postman

  • How do you organise requests into collections and folders?
  • How do you use environments and variables across requests?
  • How do you write tests and assertions in the Tests tab?
  • How do you chain requests and pass data between them?
  • How do you automate a collection run with Newman?

Cypress

  • How does Cypress differ from Selenium in architecture?
  • How do you handle asynchronous commands and the Cypress chain?
  • What are custom commands and when would you use them?
  • How do you stub network requests with cy.intercept()?
  • How do you handle file uploads and downloads in Cypress?

Appium

  • What is Appium and how does it support cross-platform mobile testing?
  • How do you locate elements in a native mobile app?
  • How do you handle gestures like swipe, scroll, and long press?
  • How do you test hybrid apps and switch to web views?
  • How do you run tests on real devices versus emulators?

Behavioral

Practice the people-and-scenario questions, using the STAR method (Situation, Task, Action, Result).

  • Tell me about yourself and your testing experience.
  • Describe a time you found a critical bug close to release. What did you do?
  • Tell me about a disagreement with a developer about a defect. How did you resolve it?
  • Give an example of a time you had to test under a tight deadline.
  • Describe a mistake you made and what you learned from it.
  • How do you handle pressure when a release is at risk?
  • Tell me about a time you improved a process or took initiative.
  • Why do you want to work here, and where do you see yourself in a few years?

Coding

Practice writing and reasoning about code — commonly asked for automation and SDET roles.

  • Reverse a string and check whether it is a palindrome.
  • Find the first non-repeating character in a string.
  • Count the occurrences of each word in a sentence.
  • Write a function to check whether a number is prime.
  • Find duplicate values in an array and remove them.
  • Sort a list of objects (e.g. users by age) without a built-in sort key.
  • Explain the difference between a list and a dictionary, with an example.
  • Write a function that reads a file and returns the most frequent line.
  • Given a web page, outline the code to find all broken links.
